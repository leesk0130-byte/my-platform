온라인 결제 사기 예방 가이드

2026년 3월 31일 · 약 8분 읽기

온라인 결제 사기는 해마다 증가하고 있으며, 가맹점이 입는 피해도 커지고 있습니다. 사기 거래가 발생하면 상품 손실, 차지백(Chargeback) 수수료, 브랜드 신뢰 하락이라는 삼중고를 겪게 됩니다. 2024년 기준 국내 온라인 결제 사기 피해 규모는 약 3,000억 원으로 추정됩니다. 이 가이드에서는 주요 사기 유형을 파악하고, 이를 예방하는 실무적인 방법을 안내합니다.

주요 결제 사기 유형

1. 도용카드 사기 (Stolen Card Fraud)

타인의 카드 정보를 탈취하여 온라인에서 부정 결제하는 가장 흔한 유형입니다.

  • 수법: 피싱, 해킹, 다크웹에서 카드 정보 구매 등으로 취득한 카드 번호·유효기간·CVC를 사용
  • 특징: 실제 카드 소유자가 아닌 제3자가 결제하므로, 나중에 카드 소유자가 이의를 제기하면 차지백이 발생
  • 피해 규모: 전체 온라인 결제 사기의 약 50~60%를 차지

2. 우호적 사기 (Friendly Fraud)

정상적으로 본인이 결제했음에도, 카드사에 "내가 결제한 적 없다"고 허위 신고하여 환불받는 사기입니다.

  • 수법: 상품을 수령한 후 카드사에 부인(Dispute) 접수 → 차지백으로 대금 회수
  • 특징: 본인 결제이므로 탐지가 어렵고, 입증 책임이 가맹점에 있어 방어가 까다로움
  • 변형: 가족(자녀 등)이 무단 결제한 후 부모가 이의 제기하는 경우도 포함

3. 계정 탈취 (Account Takeover, ATO)

쇼핑몰 회원의 계정을 해킹하여 저장된 결제수단으로 부정 구매하는 유형입니다.

  • 수법: 크리덴셜 스터핑(다른 사이트에서 유출된 ID/PW 대입), 피싱 메일, 소셜 엔지니어링
  • 특징: 기존 회원의 정상 행동 패턴으로 위장하므로 탐지가 어려움
  • 피해: 회원의 저장된 카드·포인트·적립금까지 피해 범위가 넓음

4. 삼각 사기 (Triangulation Fraud)

사기꾼이 가짜 쇼핑몰을 운영하면서 정상 쇼핑몰을 이용하는 교묘한 수법입니다.

  1. 사기꾼이 파격 가격의 가짜 쇼핑몰을 개설
  2. 소비자가 가짜 쇼핑몰에서 주문하고 카드 정보를 입력
  3. 사기꾼이 탈취한 카드 정보로 정상 쇼핑몰에서 상품을 구매하여 소비자에게 배송
  4. 소비자는 상품을 받아 만족하지만, 나중에 카드 도용이 발각되면 정상 쇼핑몰에 차지백 발생

PG사 제공 보안 기능

주요 PG사가 제공하는 보안 기능을 활용하면 사기 거래를 상당 부분 차단할 수 있습니다.

3D Secure (3DS)

카드사가 제공하는 추가 본인인증 프로토콜입니다. 결제 시 카드사 앱이나 SMS 인증으로 한 번 더 본인 확인을 거칩니다.

  • 장점: 본인인증을 거치므로 도용카드 사기를 효과적으로 차단. 3DS 인증을 거친 거래는 차지백 책임이 카드사로 전환(Liability Shift)
  • 단점: 추가 인증 단계가 결제 이탈을 유발할 수 있음 (3DS 2.0에서는 위험도 기반 인증으로 마찰 최소화)

FDS (Fraud Detection System, 이상거래 탐지 시스템)

PG사가 거래 데이터를 실시간으로 분석하여 의심 거래를 자동 탐지·차단하는 시스템입니다.

  • 분석 요소: 거래 금액, 빈도, 시간대, IP 주소, 기기 정보, 구매 패턴 등
  • 동작 방식: 위험 점수(Risk Score)를 산출하여 기준 이상이면 결제 차단 또는 추가 인증 요구
  • 가맹점 설정: PG사에 따라 FDS 규칙(금액 상한, 일일 거래 건수 제한 등)을 가맹점이 직접 설정할 수 있음

본인인증

국내 결제에서는 휴대폰 본인인증, 공동인증서, 간편인증 등으로 결제자가 본인인지 확인합니다.

  • 휴대폰 인증: SMS 또는 인증 앱으로 실명 확인
  • 생체인증: 지문, 안면인식 등 (간편결제 앱)
  • ARS 인증: 전화를 통한 추가 본인 확인

가맹점 자체 방어 전략

PG사의 보안 기능에만 의존하지 말고, 가맹점 차원에서도 방어 체계를 구축해야 합니다.

1. 주문 검토 프로세스

  • 일정 금액 이상(예: 50만 원) 주문은 수동 검토 후 발송
  • 신규 고객의 고액 주문은 전화 확인을 거친 후 배송
  • 배송 전 주문자 연락처로 주문 확인 문자/카톡 발송

2. 기술적 방어

  • 속도 제한(Rate Limiting): 동일 IP에서 단시간 내 다수 결제 시도 시 차단
  • CAPTCHA: 봇에 의한 자동 결제 시도를 방지
  • 기기 핑거프린팅: 동일 기기에서 복수 계정 사용 탐지
  • AVS(Address Verification): 카드 등록 주소와 배송지 일치 여부 확인 (해외 결제 시)
  • CVV 필수 요구: 카드 뒷면 보안 코드를 반드시 입력하게 설정

3. 정책적 방어

  • 환불 정책 명확화: 환불 조건, 기한, 절차를 명확히 고지하여 우호적 사기를 억제
  • 배송 추적 필수: 모든 주문에 배송 추적번호를 부여하여 "미수령" 주장에 대응
  • 수령 확인: 고가 상품은 수령 시 서명을 요구
  • 구매 한도 설정: 계정당·일일·월간 구매 한도를 설정
  • 블랙리스트 관리: 사기 이력이 있는 주소, IP, 이메일, 전화번호를 블랙리스트로 관리

4. 내부 보안

  • 관리자 계정에 2단계 인증(2FA) 필수 적용
  • 직원의 고객 결제 정보 접근 권한을 최소한으로 제한
  • 정기적인 보안 교육 실시
  • PCI DSS 준수 환경 유지

사기 피해 발생 시 대응 절차

사기 거래가 확인되면 신속하게 대응해야 추가 피해를 막을 수 있습니다.

즉시 대응 (0~24시간)

  1. 해당 거래 중지: 아직 배송 전이면 즉시 배송을 보류합니다
  2. PG사 통보: PG사에 사기 의심 거래를 신고하고, 해당 결제수단 차단을 요청합니다
  3. 증거 보존: 주문 내역, IP 로그, 결제 기록, 고객 연락 내역 등 모든 증거를 캡처·저장합니다
  4. 추가 거래 차단: 동일 카드·IP·배송지에서의 추가 주문을 차단합니다

단기 대응 (1~7일)

  1. 카드사 연락: 도용카드 사기인 경우, 카드사에 부정사용 신고를 접수합니다
  2. 수사 기관 신고: 경찰 사이버수사대에 피해 사실을 신고합니다 (사이버범죄 신고 시스템: ecrm.police.go.kr)
  3. 차지백 대응 준비: 카드사로부터 차지백 통보가 오면, 정당한 거래임을 입증할 자료를 준비합니다
  4. 피해 금액 산정: 상품 원가, 배송비, 수수료 등 총 피해 금액을 정리합니다

차지백 대응 방법

차지백이 발생하면 가맹점은 대표(Representment) 절차를 통해 이의를 제기할 수 있습니다.

  • 필요 서류: 배송 완료 증빙(송장번호, 서명), 주문 내역, 고객 커뮤니케이션 기록, IP 로그, 본인인증 기록
  • 대응 기한: 차지백 통보 후 보통 7~14일 이내에 반박 자료를 제출해야 합니다
  • 성공률 높이기: 3D Secure 인증 기록, 배송 추적 기록, 고객 서명 등 객관적 증거가 많을수록 유리합니다

장기 대응

  1. 패턴 분석: 발생한 사기 유형을 분석하여 방어 체계를 강화합니다
  2. FDS 규칙 업데이트: 탐지하지 못한 패턴을 FDS 규칙에 추가합니다
  3. 보험 검토: 결제 사기 보험(Chargeback Protection) 가입을 검토합니다. 일부 PG사가 유료로 제공합니다
  4. 모니터링 강화: 차지백 비율을 월별로 추적합니다. 카드사가 정한 기준(보통 1%) 이상이 되면 가맹점 제재(벌금, 계약 해지)가 발생할 수 있습니다
